This is a basic proof of concept made using the manual builder website (https://manualforarchipelago.github.io/ManualBuilder/). It generates and plays properly but is fairly rudimentary and only includes the base (Heart) roster.

Items include character unlocks, as well as permanent buffs such as max AP and hand size.
Locations include certain waves of score attack, as well as defeating bosses. Bosses can only be challenged once their corresponding character is unlocked, as well as at least one other character (to actually fight the boss with).

The goal is defeating all 8 bosses.
